Better Translation adds AI-assisted translations to your Vite app without keys, JSON
file-hopping, or a build step you have to babysit. Wrap your copy in one component and the
plugin does the rest, locally or through the hosted platform.

```bash title="Install"
bun add better-translation
```

Then add the plugin to your Vite config, mark your copy with the `T` component, and you're
translating. The rest of these docs walk through each step in detail.
