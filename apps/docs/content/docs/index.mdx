This gets Better Translation running in local dev mode. Local mode is the default: the Vite
plugin scans your app, writes generated Locale files, and generates the virtual
`better-translation/messages` module your app uses at runtime.

## 1. Install

Add the package to a Vite app running Vite 8 or later.

<Tabs items={[ "bun", "npm", "pnpm", "yarn"]} groupId="package-manager" persist>
<Tab value="bun">

```bash title="terminal"
bun add better-translation
```

</Tab>
<Tab value="npm">

```bash title="terminal"
npm i better-translation
```

</Tab>
<Tab value="pnpm">

```bash title="terminal"
pnpm add better-translation
```

</Tab>
<Tab value="yarn">

```bash title="terminal"
yarn add better-translation
```

</Tab>
</Tabs>

## 2. Configure the Vite plugin

Add the plugin to your Vite config, list your Locales, and choose the Default locale.

<Tabs items={["TanStack Start", "TanStack Router", "SvelteKit"]} groupId="app-framework" persist>
<Tab value="TanStack Start">

```ts title="vite.config.ts"
import { defineConfig } from "vite"
import react from "@vitejs/plugin-react"
import { tanstackStart } from "@tanstack/react-start/plugin/vite"
import { betterTranslation } from "better-translation/vite"

export default defineConfig({
  plugins: [
    betterTranslation({
      locales: ["en", "es", "fr"],
      defaultLocale: "en",
    }),
    tanstackStart(),
    react(),
  ],
})
```

</Tab>
<Tab value="TanStack Router">

```ts title="vite.config.ts"
import { defineConfig } from "vite"
import react from "@vitejs/plugin-react"
import { betterTranslation } from "better-translation/vite"

export default defineConfig({
  plugins: [
    betterTranslation({
      locales: ["en", "es", "fr"],
      defaultLocale: "en",
      runtime: {
        type: "local",
        target: "public",
      },
    }),
    react(),
  ],
})
```

</Tab>
<Tab value="SvelteKit">

```ts title="vite.config.ts"
import { svelte } from "@sveltejs/vite-plugin-svelte"
import { defineConfig } from "vite"
import { betterTranslation } from "better-translation/vite"

export default defineConfig({
  plugins: [
    betterTranslation({
      locales: ["en", "es", "fr"],
      defaultLocale: "en",
    }),
    svelte(),
  ],
})
```

</Tab>
</Tabs>

<Callout title="Plugin order">
  Put `betterTranslation` before the framework plugin. It rewrites Translation markers before React or Svelte transforms see your
  code.
</Callout>

## 3. Load messages and provide them

The plugin config above generates `better-translation/messages`. Load the active Locale from
that virtual module, then wrap your app with `TranslateProvider`.

Load messages before rendering your translated app, then pass them to the framework provider.

<Tabs items={["TanStack Start", "TanStack Router", "SvelteKit"]} groupId="app-framework" persist>
<Tab value="TanStack Start">

```tsx title="src/routes/__root.tsx"
import { createRootRoute, Outlet } from "@tanstack/react-router"

import { loadMessages } from "better-translation/messages"
import { TranslateProvider } from "better-translation/react"

import { getLocale } from "./-locale"

export const Route = createRootRoute({
  beforeLoad: async () => {
    const locale = await getLocale()
    const messages = await loadMessages(locale)

    return { locale, messages }
  },
  component: RootComponent,
})

function RootComponent() {
  const { messages } = Route.useRouteContext()

  return (
    <TranslateProvider messages={messages}>
      <Outlet />
    </TranslateProvider>
  )
}
```

</Tab>
<Tab value="TanStack Router">

```tsx title="src/routes/__root.tsx"
import { createRootRoute, Outlet } from "@tanstack/react-router"

import { loadMessages } from "better-translation/messages"
import { TranslateProvider } from "better-translation/react"

function RootComponent() {
  const { messages } = Route.useRouteContext()

  return (
    <TranslateProvider messages={messages}>

    </TranslateProvider>

```

</Tab>
<Tab value="SvelteKit">

```ts title="src/routes/+layout.ts"
import { loadMessages } from "better-translation/messages"

import { getLocale } from "./locale"

export async function load() {
  const locale = getLocale()
  const messages = await loadMessages(locale)

  return { locale, messages }
}
```

```svelte title="src/routes/+layout.svelte"
<script lang="ts">
  import { TranslateProvider } from "better-translation/svelte"

  let { data, children } = $props()
</script>

<TranslateProvider messages={data.messages}>
  {@render children()}
</TranslateProvider>
```

</Tab>
</Tabs>

The runtime target only changes how the generated `loadMessages` implementation gets the
Runtime bundle.

## 4. Mark copy with T

Once the provider is in place, wrap UI copy where you author it. The plugin extracts this as a
Message and gives it a stable lookup id.

<Tabs items={["React", "Svelte"]} groupId="framework" persist>
<Tab value="React">

```tsx title="CheckoutButton.tsx"
import { T } from "better-translation/react"

export function CheckoutButton() {
  return (
    <button>
      <T>Pay now</T>
    </button>
  )
}
```

</Tab>
<Tab value="Svelte">

```svelte title="CheckoutButton.svelte"
<script>
  import { T } from "better-translation/svelte"
</script>

<button>
  <T>Pay now</T>
</button>
```

</Tab>
</Tabs>

## 5. Start dev

Run your Vite dev server. The plugin scans your source and writes local Runtime bundles.

```bash title="terminal"
bun run dev
```

The default `module` target writes files under `src/lib/bt`. The `public` target writes files
under Vite's public directory, at `/bt` by default.
