## useT hook

Use `useT` for copy that must be returned as a plain string, such as labels, placeholders,
document titles, form errors, and toast messages.

```tsx title="SearchBar.tsx"
import { useT } from "better-translation/react"

export function SearchBar() {
  const t = useT()

  return <input aria-label={t("Search Projects")} placeholder={t("Search...")} />
}
```

## Context

Pass `context` as the second argument to give translation tools more information about a
plain string. Use it for copy that is short, ambiguous, or needs a specific tone.

```ts title="usage.ts"
t("Archive", { context: "Verb on a button" })
```

Context also disambiguates lookup ids. `T` and `useT` share the same lookup id behavior, so
the same source copy and options resolve to the same Message wherever they appear.

For Messages with runtime values, see [Variables](/variables).

Use `id` when a non-JSX Message needs a lookup id owned by your code.

```ts title="usage.ts"
t("Pay now", { id: "billing.checkout.submit" })
```
