---
title: Variables
description: Interpolate runtime values inside a translatable sentence with Var.
---

Runtime values should stay inside the Message so translators can move them wherever the target
Locale needs them.

## T component

Use `Var` inside `T` to interpolate JSX values without breaking the translatable sentence. The
placeholder name is part of the Message.

```tsx title="Greeting.tsx"
import { T, Var } from "better-translation/react"

export function Greeting({ name, date }: { name: string; date: string }) {
  return (
    <T>
      Hello <Var name={name} />, the date is <Var date={date} />!
    </T>
  )
}
```

The prop key becomes the placeholder name. The example above extracts the Message with `name`
and `date` placeholders and fills the values at render time.

You can also pass the placeholder name explicitly when the value is easier to read as children.

```tsx title="MessageList.tsx"
import { T, Var } from "better-translation/react"

export function MessageList({ count }: { count: number }) {
  return (
    <T>
      <Var name="count">{count}</Var> Messages need review
    </T>
  )
}
```

`Var` values can be React elements, not just raw strings or numbers. Keep inline markup inside
the placeholder value when the styling belongs to the runtime value.

```tsx title="WelcomeMessage.tsx"
import { T, Var } from "better-translation/react"

export function WelcomeMessage({ name, plan }: { name: string; plan: string }) {
  return (
    <T>
      Welcome <Var name={<b>{name}</b>} /> to the <Var plan={<b>{plan}</b>} /> plan
    </T>
  )
}
```

The example above extracts `Welcome {name} to the {plan} plan`. The `b` elements are
rendered at runtime through the placeholders, so translators can still reorder the sentence.

## useT hook

For non-JSX strings, use `{name}` placeholders and pass values as the second argument.

```tsx title="MessageSearch.tsx"
import { useT } from "better-translation/react"

export function MessageSearch({ count }: { count: number }) {
  const t = useT()

  return <input aria-label={t("Search {count} Messages", { count })} placeholder={t("Search Messages")} />
}
```

When a Message has both values and context, pass context as the third argument.

```ts title="usage.ts"
t("Moved {count} Messages", { count }, { context: "Bulk action toast" })
```

Use `Var` only with `T`. Use `{name}` placeholders with `useT` and the server translator.
