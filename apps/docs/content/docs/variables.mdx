---
title: Variables
description: Interpolate runtime values inside a translatable sentence with Var.
---

Runtime values should stay inside the Message so translators can move them wherever the target
Locale needs them.

## T component

Use `Var` inside `T` to interpolate runtime values without breaking the translatable
sentence. The placeholder name is part of the Message.

<Tabs items={["React", "Svelte"]} groupId="framework" persist>
<Tab value="React">

```tsx title="Greeting.tsx"
import { T, Var } from "better-translation/react"

export function Greeting({ name, date }: { name: string; date: string }) {
  return (
    <T>
      Hello <Var name={name} />, the date is <Var date={date} />!
    </T>
  )
}
```

</Tab>
<Tab value="Svelte">

```svelte title="Greeting.svelte"
<script lang="ts">
  import { T, Var } from "better-translation/svelte"

  let { name, date }: { name: string; date: string } = $props()
</script>

<T>
  Hello <Var name={name} />, the date is <Var date={date} />!
</T>
```

</Tab>
</Tabs>

The prop key becomes the placeholder name. The example above extracts the Message with `name`
and `date` placeholders and fills the values at render time.

You can also pass the placeholder name explicitly when the value is easier to read as children.

<Tabs items={["React", "Svelte"]} groupId="framework" persist>
<Tab value="React">

```tsx title="MessageList.tsx"
import { T, Var } from "better-translation/react"

export function MessageList({ count }: { count: number }) {
  return (
    <T>
      <Var name="count">{count}</Var> Messages need review
    </T>
  )
}
```

</Tab>
<Tab value="Svelte">

```svelte title="MessageList.svelte"
<script lang="ts">
  import { T, Var } from "better-translation/svelte"

  let { count }: { count: number } = $props()
</script>

<T>
  <Var name="count" value={count} /> Messages need review
</T>
```

</Tab>
</Tabs>

`Var` values can be formatted values, not just raw source strings. Keep formatting in the
placeholder value when it belongs to the runtime value.

<Tabs items={["React", "Svelte"]} groupId="framework" persist>
<Tab value="React">

```tsx title="WelcomeMessage.tsx"
import { T, Var } from "better-translation/react"

export function WelcomeMessage({ name, plan }: { name: string; plan: string }) {
  return (
    <T>
      Welcome <Var name={<b>{name}</b>} /> to the <Var plan={<b>{plan}</b>} /> plan
    </T>
  )
}
```

</Tab>
<Tab value="Svelte">

```svelte title="WelcomeMessage.svelte"
<script lang="ts">
  import { T, Var } from "better-translation/svelte"

  let { name, plan }: { name: string; plan: string } = $props()
</script>

<T>
  Welcome <Var name={name} /> to the <Var plan={plan} /> plan
</T>
```

</Tab>
</Tabs>

The example above extracts `Welcome {name} to the {plan} plan`. The values are rendered at
runtime through the placeholders, so translators can still reorder the sentence.

<Callout title="Var or rich text?">
  Use `Var` for a value that changes at runtime. If only the enclosed words are translated and the renderer is fixed, put the
  native element or source-owned component directly inside `T`; Better Translation handles it as rich text without a renderer
  registry.
</Callout>

## Plain strings

For non-component strings, use `{name}` placeholders and pass values as the second argument.

<Tabs items={["React", "Svelte"]} groupId="framework" persist>
<Tab value="React">

```tsx title="MessageSearch.tsx"
import { useT } from "better-translation/react"

export function MessageSearch({ count }: { count: number }) {
  const t = useT()

  return <input aria-label={t("Search {count} Messages", { count })} placeholder={t("Search Messages")} />
}
```

</Tab>
<Tab value="Svelte">

```svelte title="MessageSearch.svelte"
<script lang="ts">
  import { getT } from "better-translation/svelte"

  let { count }: { count: number } = $props()

  const t = getT()
</script>

<input aria-label={t("Search {count} Messages", { count })} placeholder={t("Search Messages")} />
```

</Tab>
</Tabs>

When a Message has both values and context, pass context as the third argument.

```ts title="usage.ts"
t("Moved {count} Messages", { count }, { context: "Bulk action toast" })
```

Use `Var` only with `T`. Use `{name}` placeholders with `useT`, `getT`, and the runtime translator.
